# NKUST 校務行政 Email 撰寫風格

## 目的

當使用者需要撰寫下列內容時，使用此 Skill：

* 校務公告
* 行政通知
* 系統維護通知
* 施工或設施公告
* 停車、交通、門禁通知
* 校園安全宣導
* 防颱、防災通知
* 申請通知
* 期限提醒
* 學籍或行政程序通知
* 活動或問卷宣傳
* 全校性學生通知
* 教職員生共同通知

核心目標是：

> 將資訊整理成「正式、清楚、具行政公文感，但仍適合 Email 閱讀」的繁體中文內容。

---

# 語言

一律使用：

* 繁體中文
* 台灣行政機關常用詞彙
* 正式書面語
* 明確日期、時間、地點與對象

避免：

* 中國大陸行政用語
* 過度口語
* 網路流行語
* 不必要的英文
* AI 常見空泛開場
* 過度華麗修辭

除非使用者要求「活動宣傳模式」，否則不要大量使用 Emoji。

---

# 預設寫作模式

預設使用：

`formal_notice`

可依內容切換：

* `formal_notice`
* `application_notice`
* `safety_notice`
* `system_notice`
* `promotion_notice`

如果使用者沒有指定模式，自動判斷。

---

# 1. Formal Notice

適用：

* 一般校務公告
* 設施公告
* 施工公告
* 停車公告
* 行政作業公告
* 政策通知

整體語氣：

> 正式、中性、直接、尊重受文者、不帶情緒。

常用標題：

```text
【公告事項】--有關○○○○，請查照。
```

```text
【公告事項】--因應○○○○，敬請配合辦理，請查照。
```

```text
【公告事項】--○○○○公告
```

---

# 2. Application Notice

適用：

* 停車證
* 補助申請
* 獎學金
* 文件繳交
* 資格申請
* 系統申請

標題優先使用：

```text
【申請通知】--有關○○○○申請時間及注意事項，請查照。
```

或：

```text
【申請通知】--○○○○申請作業，自○月○日起辦理。
```

正文務必明確列出：

1. 申請對象
2. 申請期間
3. 申請資格
4. 申請方式
5. 操作流程
6. 應備文件
7. 注意事項
8. 承辦窗口

不得把重要期限藏在長段落中。

---

# 3. Safety Notice

適用：

* 校園安全
* 交通安全
* 颱風
* 防災
* 防空演習
* 危險區域
* 動植物出沒
* 緊急事件

標題可使用：

```text
【宣導事項】--○○○○，請師長、同仁及同學多加注意安全。
```

或：

```text
【公告事項】--因應○○○○，敬請各單位配合相關安全措施，請查照。
```

內容順序：

1. 說明原因
2. 說明可能風險
3. 列出地點或期間
4. 明確要求應採取的行動
5. 提供緊急聯絡方式

語氣應嚴謹但避免製造恐慌。

可使用：

* 為維護教職員生安全
* 為預防○○情形發生
* 敬請多加注意自身安全
* 請勿靠近○○區域
* 如遇緊急事件，請立即○○
* 敬請配合相關安全措施

---

# 4. System Notice

適用：

* 系統停機
* 系統維護
* 系統故障
* 網路服務異常
* 系統恢復

標題模式：

```text
【公告事項】--本校○○系統停機維護公告，請查照。
```

```text
【公告事項】--調整○○系統停機維護時間，請查照。
```

正文依序交代：

1. 哪個系統
2. 為何停機
3. 停機開始時間
4. 預計恢復時間
5. 受影響功能
6. 使用者應提前完成哪些事情
7. 是否會另行通知

常見措辭：

```text
請於停機前完成相關作業或儲存正在登打之資料，以免資料遺失。
```

```text
若維護作業提前完成，系統將提前恢復使用，不另行通知。
```

```text
造成不便，敬請見諒。
```

---

# 5. Promotion Notice

只有以下內容才使用：

* 問卷
* 活動報名
* 校園活動
* 招募
* 投票
* 推廣活動

可以稍微活潑。

例如：

```text
【公告事項】--【最後倒數】○○活動即將截止！
```

正文可以：

* 使用較短段落
* 使用少量 Emoji
* 強調截止時間
* 強調參加資格
* 明確放置報名網址
* 使用 CTA

例如：

```text
📌 活動資訊
⏰ 報名期間
👨‍🎓 參加資格
🔗 報名連結
```

但仍應保留行政單位身份。

結尾仍使用：

```text
○○單位 敬啟
```

並附聯絡資訊。

不要把整封行政 Email 寫成廣告文案。

# 「說明」段落寫法

正式行政通知非常重視條列。

資訊超過兩項時，優先：

```text
說 明：

一、……

二、……

三、……
```

下一層使用：

```text
（一）……

（二）……

（三）……
```

再下一層：

```text
1. ……
2. ……
3. ……
```

不要使用過深的 Markdown 巢狀 Bullet List 取代行政編號。

---

# 段落邏輯

行政信正文通常依照以下順序：

## 第一段：為什麼通知

常用：

```text
依據○○○○辦理。
```

```text
因○○○○，爰辦理○○○○。
```

```text
為○○○○，特公告相關事項如下。
```

```text
本校將於○○○○辦理○○○○。
```

---

## 第二段：發生什麼事

清楚交代：

* 日期
* 時間
* 地點
* 對象
* 事項
* 原因

不要省略關鍵條件。

---

## 第三段：收件人要做什麼

優先使用明確動詞：

```text
請於○月○日前完成……
```

```text
敬請於施工期間勿進入……
```

```text
請各單位配合……
```

```text
惠請詳閱附件……
```

```text
請提前完成相關資料儲存……
```

避免只說：

```text
請大家注意。
```

應具體說明「注意什麼」。

---

# 日期與時間

行政通知必須精確。

推薦：

```text
115年9月21日（星期一）前
```

```text
115年7月14日（二）12時至18時
```

```text
7月24日（星期五）17時30分
```

如果原始資料只有西元日期，不要擅自轉民國年，除非使用者要求或完整正式通知需要。

如果日期、星期、時間彼此矛盾：

> 不要自行猜測。

應指出資料可能有誤。

# 行政文體特徵

文字應具有以下特性：

## 1. 先講事實

少寫情緒。

錯誤：

```text
我們很高興地通知大家一個非常重要的消息！
```

行政風格：

```text
本校○○系統將於115年9月10日辦理系統維護。
```

---

## 2. 行動導向

每封信應能回答：

```text
誰需要做？
做什麼？
何時以前？
在哪裡？
怎麼做？
有問題找誰？
```

---

## 3. 客氣但不冗長

使用：

```text
敬請
惠請
請
謝謝合作
請查照
敬請見諒
```

但不要每一句都加入敬語。

---

## 4. 高資訊密度

避免：

```text
為了讓整體活動可以更加順利地進行，因此在此特別提醒大家……
```

改成：

```text
為利活動順利進行，請於○月○日前完成報名。
```

# Emoji 使用規則

`formal_notice`：

```text
禁止或幾乎不用 Emoji。
```

`promotion_notice`：

每個資訊區塊最多使用一個 Emoji。

例如：

```text
📌 活動資訊
⏰ 活動期間
👨‍🎓 參加資格
🔗 報名連結
```

不要：

```text
🔥🔥🔥快來報名🔥🔥🔥
```

# 結尾格式

正式通知預設：

```text
{行政單位} 敬啟

聯絡人：{姓名}
分機：{分機}
e-mail：{Email}
```

系統寄送時可追加：


如果不是系統信箱，不得自行加入這句。

# 不得虛構

這是本 Skill 最重要的規則之一。

永遠不得自行捏造：

* 文號
* 承辦人姓名
* 分機
* Email
* 日期
* 截止期限
* 法規名稱
* 教育部函號
* 活動網址
* 申請網址
* 校區
* 附件
* 主管機關
* 申請資格
* 處罰方式
* 「逾期不受理」
* 「不另行通知」

如果使用者未提供資料：

使用 `{待提供}`。

例如：

```text
聯絡人：{待提供}
分機：{待提供}
```

不要猜。

---

# 不要過度修正文意

如果任務是「重寫既有行政信」：

保留原信的：

* 日期
* 數字
* 地點
* 人名
* 單位
* 網址
* 文號
* 規定
* 行政依據
* 附件名稱

只調整：

* 文句
* 結構
* 可讀性
* 行政語氣
* 標題

不得自行改變政策內容。

# 生成流程

每次寫信前，在內部依序判斷：

1. 收件者是誰？
2. 寄件單位是誰？
3. 這封信屬於哪個模式？
4. 核心事件是什麼？
5. 是否有期限？
6. 收件人是否需要採取行動？
7. 是否有附件？
8. 是否有承辦窗口？
9. 是否需要完整公文欄位？
10. 哪些資訊不可自行推測？

然後才開始撰寫。

# 施工／設施範本

```text
主旨：【公告事項】--有關{校區／地點}{施工事項}，請查照。

說 明：

一、為{施工目的／原因}，預定辦理{施工事項}。

二、施工時間自{開始日期}至{結束日期}，施工範圍為{地點}。

三、施工期間{道路／設施／區域}將暫停使用或實施管制。

四、敬請各位師長、同仁及同學於施工期間勿進入作業區域，並配合現場相關管制措施。
```
