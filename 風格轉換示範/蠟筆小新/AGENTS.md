# AGENTS.md — 蠟筆小新風格圖像轉換代理

## 任務目標
將使用者上傳的人物照片轉換成《蠟筆小新》動畫世界中的 2D 角色。必須保留人物辨識度，同時讓角色自然融入作品特有的簡單、可愛、無厘頭與日常搞笑動畫風格。

## 輸入
- 使用者上傳的人物照片，作為唯一人物參考。

## 人物身份保留規則
必須保留：
- 臉部辨識度
- 五官比例
- 眼睛位置
- 鼻子
- 嘴型
- 臉型
- 髮型輪廓
- 髮色特徵
- 性別表現
- 年齡感
- 主要個人特徵

不得：
- 替換成其他人的臉
- 隨機改變五官
- 因卡通化而完全失去本人辨識度

## Q 版比例規則
- 頭部比例較大
- 身體短、胖、圓潤
- 四肢簡化
- 五官線條簡潔
- 整體具有 Q 版日常動畫角色比例

## 臉部轉譯規則
以蠟筆小新式簡化語言重新詮釋人物：
- 眼睛可簡化成小黑點或簡單卡通眼型
- 眉毛可稍微加粗
- 鼻子與嘴巴使用極簡卡通線條
- 臉部輪廓圓潤
- 表情呆萌、調皮、無厘頭或搞笑

重點：簡化不等於抹除個人特徵。

## 髮型規則
- 保留原人物髮型輪廓與特徵。
- 改成簡化平塗造型。
- 線條俐落、形狀清楚。
- 不使用寫實髮絲。

## 服裝規則
- 優先保留原照片服裝的主要特色。
- 將服裝簡化成蠟筆小新風格的 2D 卡通服裝。
- 若需更貼合作品，可採用簡單上衣、短褲、襪子、球鞋等日常休閒服。
- 色彩鮮明但不華麗。

## 場景規則
優先使用典型日常場景：
- 日本郊區住宅街道
- 幼稚園教室
- 公園
- 家中客廳
- 春日部風格街景

戶外背景可包含：
- 低樓層住宅
- 簡單圍牆
- 電線桿
- 綠色樹木
- 藍天白雲
- 小公園遊具
- 腳踏車
- 住宅門口
- 街道轉角

室內背景可包含：
- 日式家庭客廳
- 電視
- 矮桌
- 靠墊
- 玩具
- 溫馨家庭日常氛圍

## 畫面風格
必須使用：
- 經典 2D 日式動畫
- 乾淨平塗色塊
- 簡單俐落線條
- 明亮溫暖色彩
- 童趣
- 搞笑
- 日常生活感

## 姿勢與構圖
- 人物位於畫面中央。
- 使用自然站姿或搞笑動作。
- 可使用叉腰、揮手、歪頭、傻笑、裝可愛、無厘頭姿勢。
- 鏡頭平視。
- 構圖像動畫截圖或正式角色插圖。

## 禁止事項
禁止：
- 寫實風
- 3D
- Pixar 風
- 複雜華麗插畫
- 其他日漫風格
- 真實皮膚質感
- 寫實髮絲
- 過度精細渲染
- 臉部走樣
- 人物辨識度消失
- 廉價變形
- 手指錯誤
- 多餘肢體
- 奇怪表情
- 文字
- watermark
- logo

## 驗收標準
1. 一眼可辨認是原照片中的人物。
2. 一眼可辨認角色已進入蠟筆小新的 2D 動畫世界。
3. 人物與背景必須使用一致的簡化平塗動畫語言。
4. 整體呈現自然、可愛、幽默、生活化，而不是高精緻日漫插畫。
