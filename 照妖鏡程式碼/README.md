# NKUST 通訊錄照片與綽號

這是一個 Manifest V3 Chrome 擴充功能。開啟高科大 elearning 任一課程的「通訊錄」頁籤後，它會依卡片上的姓名核對 `114`、`115` 名單，使用本機照片取代頭像，並在姓名下方顯示綽號。

## 安裝

1. 在 Chrome 開啟 `chrome://extensions/`。
2. 開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」。
4. 選取整個 `D:\照妖鏡` 資料夾。
5. 回到 elearning；若課程頁原本已開啟，重新整理一次。

## 使用與更新

- 功能會套用在 `https://elearning.nkust.edu.tw/moocs/` 下的所有課程，不綁定特定課程編號。
- 只有姓名能在本機名單中唯一核對到的人會套用，遇到同名資料會刻意略過，避免放錯照片。
- 要調整綽號或照片，編輯 `114/114名單簡單.json`、`115/115名單簡單.json` 或對應 PNG，然後在 `chrome://extensions/` 按本擴充功能的「重新載入」。
- 擴充功能不修改校方 API 或伺服器資料；名單由本機 service worker 讀取，只有照片會作為限於 elearning 網域的擴充功能資源顯示在卡片中。

## 檔案

- `manifest.json`：Manifest V3 設定與網站範圍。
- `background.js`：從本機 JSON 讀取並驗證名單。
- `content.js`：觀察單頁應用程式動態內容、核對姓名並修改卡片。
- `content.css`：照片與綽號標籤樣式。
- `114/`、`115/`：原始名單與照片。
